# 마커 데이터 (CSV)

`MarkerDataImportRunner`(main 실행)가 이 폴더의 CSV 4개를 읽어 `marker` 테이블에 넣는다. 인코딩은 **CP949**(UTF-8로 바꾸면 `MarkerImportService` 의 `CSV_CHARSET` 도 바꿔야 한다).

## 들어 있는 범위: 서울 + 경복대학교 남양주캠퍼스 주변
용량(전국 원본은 CSV 합계 약 400MB, GitHub 파일 한도 100MB)과 적재 시간 때문에, 앱을 쓰는 지역만 남겼다.
- **서울**: 주소가 `서울`로 시작하는 행(주소가 비어 있으면 서울 범위 좌표인 행)
- **경복대학교 남양주캠퍼스 반경 5km**: 캠퍼스 좌표(37.735181, 127.210602, 카카오 로컬 검색) 기준 5km 안의 행(진접읍·오남읍 일부)
- 좌표가 없거나 한국 범위를 벗어난 행은 뺐다. 원본 컬럼은 그대로다.

| 파일 | marker_type | 좌표 컬럼 | 이름 | 원본 | 넣어지는 건수 (서울 / 캠퍼스 5km) |
|---|---|---|---|---|---|
| `CCTV정보.csv` | `CCTV` | `WGS84위도`, `WGS84경도` | `CCTV` | 377,278 | 58,629 (58,297 / 332) |
| `전국보안등정보표준데이터.csv` | `SECURITY_LIGHT` | `위도`, `경도` | `보안등` | 1,857,668 | 149,546 (146,971 / 2,575) |
| `전국안심지킴이집표준데이터.csv` | `SAFE_HOUSE` | `위도`, `경도` | `점포명` | 2,817 | 724 (724 / 0) |
| `안전비상벨위치정보.csv` | `EMERGENCY_BELL` | `WGS84위도`, `WGS84경도` | `비상벨` | 88,634 | 26,376 (26,166 / 210) |

합계 **235,275건**. 실제 적재 코드(`MarkerImportService`)를 가짜 저장소로 돌려 건수를 확인했다(제외 0건, DB 없이).
캠퍼스 주변에는 안심지킴이집 데이터가 없다(0건).

## 범위를 넓히려면
원본은 `자료/데이터파일/` 에 있다(보안등 전국은 `전국보안등정보표준데이터_전체.csv`, 약 294MB). 원본을 이 폴더에 같은 이름으로 덮어쓴 뒤 적재하면 전국이 들어간다. 다만 적재가 오래 걸리고(건별 저장) DB 도 커진다.

## 적재할 때 주의
- 이미 `marker` 에 데이터가 있으면 같은 데이터가 **중복으로 또 들어간다**(적재 코드에 중복 검사가 없다). 다시 넣으려면 `DELETE FROM marker WHERE marker_type <> 'PLACE';` 로 먼저 지운다(`PLACE` 는 사용자가 즐겨찾기한 장소).
- 지도 범위 조회가 느리면 `marker (marker_type, latitude, longitude)` 에 인덱스를 추가한다.
